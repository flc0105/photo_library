  3. Geometry Status：Perfect = 像素足够且比例精确为 2:3 / 3:2；Slight Off = 像素足够、比例非精确且 center-crop loss ≤ 3%；Ratio Error = 像素足够、比例非精确且 center-crop loss > 3%；Low Res = 像素不足，不论比例；Read Error = 无法读取有效宽高。
  4. 像素足够：Portrait / Square 必须至少 3200×4800，Landscape 必须至少 4800×3200。判断使用源图当前宽高；center crop 只能减少像素，因此不能修复 Low Res。
  5. Crop loss：按中心裁切到精确 2:3 / 3:2 后，被裁掉的面积占源图面积的比例。3% 是 Slight Off / Ratio Error 的分界，并与 Final Builder 的 crop warning threshold 对齐。Geometry Detail 继续显示 Resolution、Current ratio、必要时的 Target ratio，以及非 Final 阶段的 Center crop / Crop loss。
  6. 顶部统计：总文件统计四个阶段实际扫描到的文件数；Perfect统计像素足够且精确比例；Low Res统计像素不足，当前 Read Error 也会归入这一计数；顶部 Ratio Error 是所有“像素足够但比例非精确”的汇总，因此同时包含表内的 Slight Off 与 Ratio Error。
  7. Key EXIF：字段列表来自 data/final_metadata_settings.json，与 Write Metadata 使用同一份 contract。Base / Model / Revision 按配置的 source tag 优先级读取并统计存在项；Final 必须使用配置定义的 output tag，并且除允许的 EXIF 结构字段、JFIF、ICC 外不能有额外业务 metadata。
